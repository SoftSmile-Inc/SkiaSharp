# Curated release facts for 4.150.2

## Bug fixes

### Ganesh failed-work handling

**Release-note blurb:** Fixes stale GPU readbacks, restores resolve/mipmap dirty
tracking after failed work, checks internal flush results, and corrects
framebuffer deletion on Imagination GPUs.

**Evidence:** [#4517](https://github.com/mono/SkiaSharp/pull/4517) carries the
stale-readback and resolve dirty-tracking fixes.
[#4561](https://github.com/mono/SkiaSharp/pull/4561) carries the internal-flush,
failed resolve/mipmap, and Imagination framebuffer fixes.

### SkSL RasterPipeline map-pointer lifetime

**Release-note blurb:** Fixes a use-after-free in SkSL RasterPipeline code
generation by dereferencing a child-effect map entry before the map can grow
and invalidate its pointer.

**Evidence:** [#4648](https://github.com/mono/SkiaSharp/pull/4648) first moves
the shipped Skia tree to the commit containing the runtime fix and its
regression test. [#4663](https://github.com/mono/SkiaSharp/pull/4663) repairs
the recorded upstream merge ancestry but has no additional file-tree delta.

**Attribution:** Cite #4648 for the runtime fix. Do not create a separate
consumer-facing bullet for #4663.
