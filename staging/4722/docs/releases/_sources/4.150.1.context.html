      Advance the externals/skia submodule (and cgmanifest.json) on the release/4.150.x line to mono/skia@ef2ebb78c8, pulling in one upstream chrome/m150 bug fix:

      • Fix Use-After-Free in SubRunAllocator (google/skia@3273c66a68)

      Deserializing a corrupt Slug buffer (SlugImpl::MakeFromBuffer) returns nullptr early and destroys a std::tuple whose member destruction order is unspecified, so SubRunInitializer freed the backing memory before ~BagOfBytes in the SubRunAllocator read fEndByte out of it -- a use-after-free read followed by a wild-free/double-free. Upstream replaces the tuple with a struct that guarantees the allocator destructs before the initializer frees the memory. See mono/skia#281 for the full analysis.

      Submodule bump only: cgmanifest.json commitHash tracks the new mono/skia commit; chrome_milestone (150) and upstream_merge_commit (3273c66a68) are unchanged (same-milestone release-line sync, no version bump). The upstream change is internal C++ (src/text/gpu/SubRunAllocator.h) with no C API or binding impact -- binding regeneration produced zero diff and the full SkiaSharp.Tests.Console suite passed (5584 passed, 0 failed, 172 skipped) on Linux x64.
